# Weather App

A simple weather app built with HTML, CSS, and JavaScript.

## Features
- Search weather by city
- Real-time API data
- Dynamic background changes
- Responsive UI

## Tech Stack
- HTML
- CSS
- JavaScript
- OpenWeatherMap API

##SETUP

1. Get your API key by logging in on https://openweathermap.org/
2. In 'script.js' file swap 'YOUR_API_KEY' from the first line of code to your actual API key from OpenWeatherMap
3. Run the HTML file
